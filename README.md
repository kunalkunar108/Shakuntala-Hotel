# Shakuntala Hotel — Demo Website

A responsive static website concept for Shakuntala Hotel near Massanjore Dam, Dumka district, Jharkhand.

## Included
- Responsive homepage and mobile navigation
- Hotel overview and listed amenities
- Dining information
- Massanjore Dam section and Google Maps directions link
- Click-to-call contact buttons
- Basic SEO metadata and responsive design

## Deployment
This is a static HTML website. Import this repository into Vercel and deploy using the **Other** framework preset. No build command, database, Firebase, environment variables, or backend is required.

## Demo limitations
No live room availability, reservation engine, online payments, or admin dashboard is included. Confirm all hotel details and replace sample stock photography with approved hotel photos before using this as the hotel's official site.
